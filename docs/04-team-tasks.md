# 团队成员任务分工

具体数据结构、接口和协作规范以现有设计文档为准。公共契约变更须先与项目负责人确认并同步文档。

## 项目负责人

- 工作职责：总体架构、需求分析、数据库设计、接口规范、代码审查、系统集成和最终验收。
- 负责模块：总体设计、公共数据库与 API 契约、集成与验收。
- 具体功能：明确需求和边界，协调设计变更，审查实现并组织端到端集成。
- 主要交付物：经确认的设计与接口规范、审查反馈、集成与验收结果。
- 验收标准：设计和契约一致，主要流程按确认的需求完成集成并通过验收。
- 接口依赖：与 A 确认页面需求，与 B 确认数据及 API 契约，与 C 确认轨迹采集和测试边界。

## 成员 A：前端

- 工作职责：负责 Vue 3 前端开发。
- 负责模块：系统总览、Agent 与任务管理、Trace 展示、日志查询和性能分析页面。
- 具体功能：实现上述页面及其交互，按约定调用 API 并展示结果。
- 主要交付物：前端页面、接口对接和必要测试。
- 验收标准：页面满足确认的需求，能够展示后端返回的数据并完成约定交互，必要测试通过。
- 接口依赖：依赖 B 提供符合规范的 API；与负责人确认交互及契约变更，并使用 C 生成的数据进行联调。

## 成员 B：后端与数据库

- 工作职责：负责 FastAPI 后端与 PostgreSQL 数据库。
- 负责模块：数据库建表、业务 API、Trace 查询、事务处理、索引设计及性能优化实验。
- 具体功能：按数据库和 API 规范实现存储及查询、事务和索引，并开展性能对比实验。
- 主要交付物：数据库迁移、后端接口、测试与数据库性能实验记录。
- 验收标准：建表和接口符合经确认的规范，主要查询与事务行为通过测试，实验过程与结果可复现。
- 接口依赖：依据负责人确认的数据库及 API 契约实现；为 A 提供接口，与 C 协调轨迹写入和测试数据。

## 成员 C：模拟器与测试

- 工作职责：负责 Agent 模拟器、轨迹采集、模拟数据、真实模型适配和系统测试。
- 负责模块：Agent 模拟器、TraceRecorder、模拟数据生成、真实模型 Adapter 和系统测试。
- 具体功能：模拟 Agent 执行并记录轨迹，生成测试数据，按确认的接口接入模型适配器，开展系统测试。
- 主要交付物：模拟器、记录器、数据生成工具、模型适配器及测试记录。
- 验收标准：模拟数据和轨迹符合约定，可用于端到端联调；适配器和系统测试满足确认的需求，测试结果可核查。
- 接口依赖：与 B 对齐数据结构及写入接口，向 A 提供联调数据；模型接入边界和凭据配置与负责人确认。
