## 3. 性能、资源与视觉目标

基准环境建议至少4逻辑CPU、8GiB可用内存、本地SSD；实际机器配置必须记录。以下为该参考环境下的工程目标，需要实测，不构成当前性能声明：

- 50逻辑节点/500 Span，桌面1440×900首次图可交互P95<=2秒；节点选择/高亮P95<=100ms；不出现超过1秒的主线程卡死。移动端允许只读图+详情/列表替代编辑。
- 100K/1M隔离数据集的单Run轨迹读取、最近50条日志和普通游标下一页：warm-cache API P95目标<=500ms；端到端页面可用<=2秒。查询精确总数、全量导出及实验排除在普通请求目标之外，另列耗时。
- 健康本地网络、2Worker/4并行节点下，已提交journal到浏览器可见P95<=1秒；取消请求到停止新步骤P95<=2秒。CPU饱和/数据库不可用单列，不删慢样本。
- 1API+2Worker的连接池总预算默认<=20个PG连接；SSE不每客户端常驻独占连接。300次/档HTTP负载记录RSS、连接、积压和清理；任务结束后无租约泄漏、遗留事务或后台无限重连。
- 1000000 Span的磁盘/索引/日志规模与生成耗时如实报告；不承诺固定每秒处理多少条。若未达上述目标，必须给瓶颈、优化前后证据及最终限制，不能只改测试阈值。

性能数至少30次请求采样；正式数据库实验仍按16的15/30次协议。mock计时不能用于这些门槛。

视觉验收需要负责人实际查看截图/浏览器：默认首页不是单一执行表单；Trace首屏有节点连线图；详情抽屉/标签页替代长ID列表；瀑布有刻度；执行中状态变化确实由SSE驱动；异常节点与日志联动；实验图含单位、样本量、误差范围和数据来源。截图漂亮不能替代交互与真实数据。

## 4. 测试入口与运行手册交付要求

负责人在G1提供专用v2集成fixture与测试入口，管理新增表、MV、触发器清理；必须拒绝非`*_test`库。B/C自有fixture不修改根conftest。运行手册至少包含：

```text
# 最终实现必须提供；以下是命令契约，不是当前可用命令。
backend/.venv/Scripts/python.exe -m app.migrate
backend/.venv/Scripts/python.exe -m app           # 兼容API入口
backend/.venv/Scripts/python.exe -m app.worker --worker-id worker-1
backend/.venv/Scripts/python.exe -m app.worker --worker-id worker-2
backend/.venv/Scripts/python.exe -m app.lab.worker --runner-id lab-1
backend/.venv/Scripts/python.exe scripts/v2/test_all.py --database PROFILE
backend/.venv/Scripts/python.exe scripts/v2/seed_demo.py --base-url URL --seed 42 --profile full
```

`scripts/v2/test_all.py`由负责人维护，虽然目录通常归C，该具体文件明确例外；`--database`为服务端配置的测试profile名，不接受密码命令行参数。Windows支持独立终端运行，自动后台启动必须无多余可见窗口，PID登记且可安全停止。README/Compose说明API、Worker、实验库与前端启动顺序，根.env.example列新开关和预算，不能覆盖用户已有.env。

最终回归分开记录：v1后端、B模块PG、C纯算法、跨模块PG、A单元/类型/构建、A mock浏览器、真实v1浏览器、真实v2全站、规模、故障、实验。不能把mock与真实的passed相加制造“全量通过”印象。已有v1的250是历史参考，新增测试数量不设灌水目标。

## 5. 12分钟汇报路线

1. 0–1分钟：问题与架构，展示总览、数据规模和研究问题。
2. 1–3分钟：工作流版本和并行/分支图，绑定Agent执行，实时图/瀑布/日志联动。
3. 3–5分钟：失败恢复与关键路径，打开同版本Run对比，解释重试代价和统计局限。
4. 5–7分钟：双Worker、租约fencing与事务原子性，演示一次预设故障和恢复证据。
5. 7–10分钟：六类实验概览，深入索引/选择率、深分页或MVCC中的两项，给原样本/计划/空间代价。
6. 10–12分钟：研究结论、失败反例、外推限制与系统边界；现场再现一个查询或报告导出。

准备可离线打开的真实结果快照、录制和报告作为网络/机器故障备用，标记为历史实测，不在现场冒充新运行。模拟器不依赖模型密钥；固定seed和演示脚本可重复。
